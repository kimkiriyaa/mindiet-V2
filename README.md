# Mindiet Meal Momentum

# 작업 범위 선언 (필독)
이번 작업은 **UI/UX 프론트엔드 뼈대와 인터랙션 프로토타입**만 구현한다.
- 모든 데이터는 로컬 상태(`React Context` + `localStorage`)와 고정된 샘플 목업(Mock) 데이터로 처리한다.
- 실제 서버 인증, 실제 AI API 호출, 외부 DB/구글 시트 통신 코드는 구현하지 말고 UI 화면, 로딩 애니메이션, 상태 전환만 완벽하게 구현해줘.
- 다이어트 앱의 직관적인 기록 대시보드와 탭 레이아웃 흐름을 참고하되, 모든 그래픽과 문구는 **'민다이어트(MinDiet)'** 자체 브랜드 스타일로 깔끔하게 새로 디자인해줘.

---

## 0. 최초 실행 & 상태 관리 (핵심 아키텍처)
- **최초 실행 온보딩 및 기본값 (`NaN` 방지)**:
  - 최초 실행 시 3단계 온보딩(① 성별·나이·키 ② 시작/목표 체중 ③ 활동량·다이어트 목표·식단 타입) 화면을 보여줄 것.
  - '건너뛰기' 클릭 시 기본 프로필(남성, 30세, 175cm, 시작 체중 70kg, 목표 체중 65kg, 보통 활동, 감량, 일반식)을 즉시 적용해 계산식에서 `NaN`이 절대 나오지 않게 할 것.
  - 일일 체중 기록이 없을 때는 프로필의 '시작 체중'을 기본 체중으로 사용.
- **전역 상태 관리 (`DietContext`)**:
  - `profile`, `식단 기록`, `운동 기록`, `체중 기록`은 하나의 전역 React Context에서 관리하고 모든 탭이 같은 상태를 구독할 것. 탭을 전환해도 입력값이 초기화되지 않고 유지되어야 함.
- **컴포넌트 분리**:
  - `HomeTab`, `CoachTab`, `BattleTab`, `MyInfoTab`, `SummaryCard`, `MealAccordion`, `AddFoodModal`, `ExerciseCard`, `WeightCard`, `BottomTabBar`, `OnboardingModal`로 명확히 분리할 것.
- **탄:단:지 g(그램) 환산 규칙**:
  - 탄:단:지 비율은 **'칼로리 기준'**으로 배분한 뒤 그램(g)으로 환산할 것.
  - 환산 계수: **탄수화물 4kcal/g, 단백질 4kcal/g, 지방 9kcal/g** (정수 반올림. 예: 목표 2000kcal, 5:3:2 비율 → 탄 250g / 단 150g / 지 44g).

## 1. 디자인 시스템 & 레이아웃 확정
- **컨셉**: 모바일 퍼스트(Mobile-first) 중앙 정렬 뷰포트(`max-width: 480px`, 화면 양옆 여백은 연한 회색 배경 처리).
- **컬러 & 아이콘**: 화이트 배경, 에메랄드 그린(`#10B981`) 메인 포인트, 목표 칼로리 초과 시 경고 컬러는 주황/코랄(`#F97316`)로 자동 전환. 아이콘은 `lucide-react`를 적극 활용.
- **캐릭터/아바타 표현**: 어색한 외부 일러스트 대신 **단순하고 귀여운 원형 아바타(이모지 조합 또는 깔끔한 SVG 아이콘)**로 통일.
- **네비게이션 (하단 고정 탭 바 - 4개 탭으로 확정)**:
  1. `홈`: 대시보드 + 식단/운동/체중 기록
  2. `AI 코치`: 영양 상담 채팅 및 식단 피드백 (목업 UI)
  3. `챌린지`: 일일 미션 체크 및 그룹 랭킹 현황판 (목업 UI)
  4. `내 정보`: 프로필 상태 및 신체 스펙·목표 칼로리 설정

## 2. 핵심 계산 규칙 (단일 출처 원칙)
- **날짜 처리 규칙**: `toISOString()` 사용 금지(UTC 오차 방지). 반드시 **로컬 타임존 기준 `YYYY-MM-DD`** 포맷 유틸 함수를 만들어 사용할 것.
- **일일 목표 칼로리 단일 함수 (`calculateDailyTargetCalories`)**:
  - 하드코딩된 2000kcal 절대 사용 금지. `홈` 탭과 `내 정보` 탭 모두 이 함수의 반환값만 참조할 것.
  - **공식 (Mifflin-St Jeor)**:
    - 남성 BMR = `10 * 체중(kg) + 6.25 * 키(cm) - 5 * 나이 + 5`
    - 여성 BMR = `10 * 체중(kg) + 6.25 * 키(cm) - 5 * 나이 - 161`
    - 체중은 '가장 최근 기록된 체중'을 우선 반영하고, 기록이 없으면 프로필의 '시작 체중'을 반영.
  - **활동계수**: 좌식 `1.2` / 가벼운 활동 `1.375` / 보통 `1.55` / 활동적 `1.725`
  - **목표 보정**: 감량 `-500kcal` / 유지 `0` / 증량 `+300kcal` (정수 반올림)
  - **안전 하한선**: 최종 목표 칼로리가 여성 1200kcal 미만이면 `1200`, 남성 1500kcal 미만이면 `1500`으로 보정.
  - **검증 기준**: 남성, 30세, 175cm, 70kg, 보통 활동(1.55), 감량(-500) 설정 시 → BMR `1649`kcal, 최종 목표 칼로리 `2056`kcal가 정확히 도출되어야 함.
- **식단 타입별 탄:단:지 권장 비율 프리셋**:
  - 일반식(`5 : 3 : 2`), 운동/고단백(`4 : 4 : 2`), 키토/저탄고지(`1 : 3 : 6`), 비건(`6 : 2 : 2`)

## 3. 탭별 상세 화면 구성

### [탭 1] 홈 (`HomeTab` - 일일 요약 & 기록 대시보드)
1. **상단 헤더 & 날짜 바**:
   - 앱 로고('민다이어트'), 사용자 닉네임, 날짜 이동(`<` 오늘 날짜 `>` + 달력 선택).
2. **메인 칼로리 요약 카드 (`SummaryCard`)**:
   - **순 섭취 칼로리 계산**: `섭취 칼로리 - 운동 소모 칼로리 = 순 섭취 칼로리`
   - 중앙 대형 프로그레스 바: `순 섭취 칼로리 / 일일 목표 칼로리`와 **"오늘 OOO kcal 남았어요"** (초과 시 주황색으로 전환되며 **"목표보다 OOO kcal 초과했어요"**) 문구 표시.
   - 하단 3분할 미니 게이지: **탄수화물 / 단백질 / 지방** 각각의 `현재 섭취 g / 목표 g` 수치와 퍼센트 바(**목표 g 대비 현재 섭취 g 비율 %**) 표시.
3. **식단 기록 섹션 (`MealAccordion` - 아코디언 카드 형태로 확정)**:
   - `아침` / `점심` / `저녁` / `간식` 4개 아코디언 카드 (헤더 우측에 각 끼니 합계 kcal 및 `+ 추가` 버튼).
   - 기록이 없을 때는 깔끔한 빈 상태(Empty State) 안내 문구 표시.
   - **음식 추가 모달 (`AddFoodModal` - 2가지 탭)**:
     - **AI 사진 스캔 탭**: 사진 업로드 시 1.5초간 스캔 로딩 애니메이션을 보여준 뒤, **고정된 샘플 분석 결과 1~2개**(예: 닭가슴살 샐러드 1인분 320kcal, 삶은 계란 2개 150kcal)를 확인 카드로 띄워 사용자가 수량을 수정(+/-)하거나 확인 후 등록하는 흐름 구현.
     - **직접 입력 탭**: 음식명, **수량(개수/인분)**, 단위 칼로리, 단위 탄단지를 입력하면 **`총 칼로리 = 단위 칼로리 × 수량`**이 실시간 계산되어 등록.
4. **운동 소모 기록 카드 (`ExerciseCard`)**:
   - 운동 종목명과 소모 칼로리(kcal)를 간단히 추가/삭제하고 상단 순 섭취 칼로리에 즉시 차감 반영.
5. **체중 기록 & 추이 차트 카드 (`WeightCard`)**:
   - 오늘의 체중 입력 폼 + 최근 14일 체중 꺾은선 차트(`recharts`).
   - 차트 내에 사용자의 **'목표 체중'을 에메랄드색 점선 기준선(`ReferenceLine`)**으로 표시.

### [탭 2] AI 코치 (`CoachTab` - 고정 샘플 목업 화면)
- 상단에 단순하고 친근한 원형 아바타(이모지/SVG)와 오늘 섭취한 탄단지 비율 요약 말풍선 배치.
- 하단에는 고정된 샘플 대화 2개(예: "점심에 단백질이 조금 부족해요! 저녁엔 닭가슴살이나 두부를 추가해 볼까요?")가 표시되는 깔끔한 채팅형 인터페이스 구성.

### [탭 3] 챌린지 (`BattleTab` - 고정 샘플 목업 화면)
- '물 2L 마시기', '세 끼 식단 기록하기', '목표 칼로리 지키기' 등 일일 미션 체크리스트(클릭 시 완료 토글 및 포인트 적립 프로그레스 바 상승).
- 하단에는 고정된 샘플 참여자 3~4명의 주간 달성률 순위를 보여주는 그룹 랭킹 카드 UI.

### [탭 4] 내 정보 (`MyInfoTab` - 프로필 & 목표 설정)
- 상단: 원형 아바타 프로필 카드 및 현재 달성 배지 요약.
- 하단 설정 폼: 성별, 나이, 키, 시작 체중, **목표 체중**, **활동량(4단계)**, **다이어트 목표(감량/유지/증량)**, **식단 타입(일반/운동/키토/비건)**.
- 폼 하단 실시간 미리보기 박스: 입력값 변경 시 즉시 계산된 **기초대사량(BMR)**, **일일 목표 섭취 칼로리(kcal)**, **탄/단/지 목표 그램(g)수**를 실시간으로 표시.
- `[저장하기]` 클릭 시 전역 Context가 업데이트되어 `홈` 탭으로 이동했을 때 모든 목표 칼로리와 탄단지 목표 g수가 즉시 똑같이 반영될 것.
